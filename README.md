# Socket.IO Chat Application 🚀

A real-time chat application built using **Node.js**, **Express**, and **Socket.IO**.  
This project demonstrates real-time communication, event handling, and basic chat features.

---

## 🔥 Features

- ✅ Real-time messaging using Socket.IO
- ✅ Nickname system
- ✅ Online users list (real-time)
- ✅ Typing indicator (`{user} is typing...`)
- ✅ Broadcast messages (sender excluded)
- ✅ Clean and simple UI

---

## 🛠️ Tech Stack

- **Backend:** Node.js, Express
- **Real-time:** Socket.IO
- **Frontend:** HTML, CSS, JavaScript
- **Version Control:** Git & GitHub
